# Console HUD

[Русский](README.md)

A TERA Toolbox mod that replaces the character HUD with a console-style layout: circular laurels, a class icon, HP, MP, gear score and class resource bars.

**Version: 0.66. Supported client: TERA 100.02, x64.** Other client patches have not been verified.


The leader crown in the custom character HUD follows the player name.


Character HP and MP number formats use the native client UI preferences and are restored on login across default, classic and console. No additional config.json fields are used.


Offline party members show the native localized status in the HP value field (`Offline` in English, «Не в сети» in Russian) of classic and console. Names stay visible and the selected HP format returns on reconnection.

Party effects below the bars remain anchored to MP while dice/results animate. Right-side effects still clear the combat and dice fields.


A reconnecting party member no longer freezes its provisional position before native saved coordinates arrive. Explicit saved positions and manual arrangements remain authoritative.


MP format persistence uses the native CWMB key directly, including when an older shared UI key class loads first. The preference stays in native client settings, with no extra config.json fields.

## Features

Removing a window releases its subscriptions, mouse handlers, effect timers, and deferred animations. Style switching reuses the existing handlers.

In `classic` and `console`, hidden native character gauges do not paint or start animations. HP, MP, and shield calculations are retained. Selecting `default` restores native gauges and class resources with current values.

- Compact and expanded character HUD layouts.
- Party design 4 with names inside HP, a separate MP bar, round laurels, individual dragging, and connectors behind the UI.
- The + button after Adventure Coins opens the native TERA Store.
- Adventure Coins to the left of the party crown: native icon, current/maximum balance, event infinity mode and native tooltip.
- Classic circular Lv65-era laurels and five ranks of console-style laurels created by us.
- Switch styles while staying on your character, including the native 100.02 HUD and laurels.
- HP and MP gradients and click-to-toggle percentages. The character HUD supports shields; the party HUD does not calculate shields.
- Warrior and sorcerer stacks, class resources, and a gear-score icon with decimal values.
- Animated energy flow for valkyrie, gunner and brawler. Valkyrie's empty `0 / 0` bar remains visible.

The console-style HUD, laurels and effects were created and generated by us from gameplay references. They are reconstructions, not original console assets, and the match is approximate. The `default` style uses the preserved native 100.02 character HUD and its original laurels.

## Requirements

- **TERA 100.02 x64**.
- TERA Toolbox with client mods and GPK loading enabled.

The game location is detected through Toolbox. No separate installer or manual mapper replacement is required.

## Installation

1. Completely close TERA and Toolbox, including its system-tray icon.
2. On the repository page, select **Code → Download ZIP**.
3. Extract the **`console-hud-master`** folder and place it in **`Toolbox/mods/`**. No renaming is required.
4. Check the resulting location:

   ```text
   TERA Toolbox/
   └─ mods/
      └─ console-hud-master/
         ├─ module.json
         ├─ index.js
         ├─ client/
         │  ├─ S1UI_CharacterWindow.gpk
         │  ├─ S1UI_PartyWindow.gpk
         │  ├─ S1UI_PartyAbnormalitySetting.gpk
         │  └─ S1UI_InteractionMenu.gpk
         └─ definitions/
   ```

5. Start **Toolbox first, then TERA**, and log into your character.

`module.json` must be directly inside `mods/console-hud-master/`, without an extra nested folder. If the repository's default branch is named `main`, the folder will be `console-hud-main`; it also works without renaming.

If Console HUD is already installed as `console-hud` or under another name, save its `config.json` (`module_settings.json` in older versions) and remove the old folder first. Restore your settings into the new folder. Keep only one copy of Console HUD in `mods`.

Do not copy the GPK into the game directory manually. Installing or updating the GPK requires restarting the client.

## Controls and commands

| Action | Control |
| --- | --- |
| Compact / expanded layout | Click the class icon |
| Expanded / vertical layout in `default` | Click the central panel |
| HP numbers / percentages | Click the HP bar |
| MP numbers / percentages | Click the MP bar |
| Classic Lv65 laurels | `chud classic` |
| Console-style laurels | `chud console` |
| Native 100.02 HUD and laurels | `chud default` |
| Toggle laurels | `chud toggle` |
| Show version and status | `chud status` |
| Reload settings from disk | `chud reload` |

Enter commands in the **Toolbox channel**. `consolehud` is an alias for `chud`, for example `consolehud classic`. If your Toolbox uses the `/8` prefix, use `/8 chud classic`.

**Classic Lv65 laurels are selected on a fresh installation.** `classic` and `console` use our HUD with different laurels. `default` restores the native 100.02 Character Window: HP, MP, class resources, laurels, gear score and other elements. All three modes switch without leaving your character or disabling the module. `toggle` alternates `classic` and `console`; from `default`, it returns to `classic`.

The only addition to the native `default` layout is clicking the central panel to switch between expanded and vertical views and save the selection. Dragging the panel does not toggle its layout.

## Party UI

In custom styles, HP and MP updates repaint only their corresponding gauge, without laying out the entire member again or drawing hidden native gauges. Returning to `default` synchronizes the native gauges with current values. Effect processing, timers, and removal retain the native implementation.

Party spacing and connectors account for the in-game UI scale. Original colored class icon textures are embedded in the party package.

Custom party styles are 25% smaller than the initial game builds, with tighter effect spacing. The in-game UI scale still applies.

Custom party styles align the class icon and wreath center with the MP bar center.


All 13 original class icons are centered from their visible bitmap bounds, separately in the party and character HUD. Colors are unchanged.


`classic`, `console`, and `default` control both HUDs. Classic and console use party design 4 with the original class icon colors, names inside HP, a separate MP bar, and connectors behind the UI. Default restores the native 100.02 party window.


Click a party member’s HP to switch between percentage and current/maximum values. The HP format is shared across party members and saved in `config.json`. Party MP has no numbers or click action.

Effects default to one row beneath MP, starting at the rectangular part of the HP bar. Open the native party gear menu and its effect settings, enable **«Показывать эффекты справа»** (Show effects on the right), and press **OK** for three effects vertically with unlimited columns to the right. This saves `partyEffectsRight` (`false` by default). Native filters, group popups, timers, and tooltips are retained. The added checkbox is hidden in default style.

The combat indicator is placed after HP. The complete dice field, including its result and item icon, is placed after MP. Right-side effects move past the current visible status fields and settings button. Bottom-row effects keep their alignment.

Drag each member by its laurel. Connectors follow actual columns, so separating one member does not remove unrelated links. The game continues to save member positions.

Right-click a party member and choose **«Осмотреть» (Inspect)** to open the native equipment inspection window. This action is available in all three styles.

Column snapping only runs while dragging the selected member. It never moves other members or repositions the party on theme or HP/MP changes. The custom party frame callback is removed when idle. Connectors update on placement events; dice bounds update only while the widget is visible. Character animations render at most 30 times per second; unchanged fills and text are cached.


Party MP is a thin 9-logical-pixel bar without numbers or a click handler; there is no separate party ST bar. Effect icons are 26 logical pixels with a 1px gap. Personal character resources and shields are preserved.

The character HUD updates static elements when data changes. Energy flow and stack pulses reuse retained geometry; hidden windows pause animations, and `default` removes the custom frame handler after acknowledging the theme.

Login theme restoration and style commands send only Console HUD keys. They do not replay saved UI scales, window positions, or other controllers.

## Settings

Toolbox stores settings in **`config.json`** inside the mod folder, for example `mods/console-hud-master/config.json`. Laurel commands save your selection; normal use does not require editing the file. Settings migration uses `settings_migrator.js`.

| Setting | Default | Meaning |
| --- | --- | --- |
| `enabled` | `true` | Load the mod when starting the client |
| `laurelStyle` | `"classic"` | `"classic"`: our HUD with Lv65 laurels; `"console"`: our HUD with laurels created by us; `"default"`: native 100.02 HUD |

After editing the style manually, run `chud reload`. Changing `enabled` takes effect after restarting the client with Toolbox.

Personal settings are excluded from the published package.

When upgrading an older installation, the migrator imports `module_settings.json` if `config.json` does not exist yet. An existing `config.json` takes precedence.

## Updating

**Automatic updates are enabled by default.** When Toolbox starts, its built-in updater checks `manifest.json` and downloads changed files from the **`master`** branch of [this repository](https://github.com/Vampical/console-hud). `config.json` is excluded from the update manifest, preserving your settings.

Close TERA before starting Toolbox with updates, wait for updates to finish, then start the game. An updated GPK takes effect on the next client launch. Module updates must be allowed in Toolbox, and Console HUD must not have updates disabled locally.

Versions before 0.40 had automatic updates disabled. Install the current ZIP manually once to upgrade to 0.40; subsequent updates do not require downloading the ZIP again.

To update manually, close the game and Toolbox, save `config.json`, select **Code → Download ZIP**, replace the mod folder, and restore your settings. Do not keep both old and new copies.

## Uninstalling

Close TERA and Toolbox, delete the mod folder (`mods/console-hud-master`), then restart the client. Toolbox's client interface loads the mod; installation does not replace the mapper files on disk.

## Troubleshooting

**The original HUD is still displayed.** Check `mods/console-hud-master/module.json`, client-mod support, and the Toolbox → TERA startup order. Check for another mod replacing the same character HUD.

**Unknown command.** Log into your character, check that `console-hud` loaded in the Toolbox log, and try `chud status` or `consolehud status` in the Toolbox channel.

**GPK checksum error.** Download the archive again using **Code → Download ZIP** and replace the entire mod folder with both the game and Toolbox closed.

**Laurels did not apply after changing characters.** Check `chud status`, then retry `chud classic` or `chud console`. Include the versions of Settings Saver / Settings Fixer if you use them and report an issue.

In **Issues**, include the client patch, Toolbox version, `chud status` output, relevant log lines and a screenshot.
