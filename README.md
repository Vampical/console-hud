# Console HUD

[English](README.en.md)

Мод для TERA Toolbox, заменяющий панель персонажа интерфейсом в консольном стиле: круглые венцы, значок класса, HP, MP, ГС и классовые шкалы.

**Версия: 0.40. Поддерживаемый клиент: TERA 100.02, x64.** Для других патчей отображение и работа модуля не подтверждены.

## Что меняется

- Компактная и развёрнутая панель персонажа.
- Классические круглые венцы эпохи Lv65 и созданные нами консольные венцы пяти рангов.
- Переключение оформления командой без выхода с персонажа, включая штатную панель и венцы 100.02.
- HP и MP с градиентами, переключением чисел в проценты, отображением щитов и штатных состояний HP.
- Стаки воина и мага, классовые ресурсы, значок и дробное значение ГС.
- Движущийся поток энергии у валькирии, ганнера и бравлера. У валькирии пустая шкала при `0 / 0` остаётся видимой.

Консольный стиль панели, венцы и эффекты созданы и сгенерированы нами по игровым референсам. Это реконструкция, а не оригинальные ресурсы консольной версии. Их соответствие примерам приблизительное. Стиль `default` использует сохранённую исходную панель 100.02 с её штатными венцами.

## Требования

- Клиент **TERA 100.02 x64**.
- TERA Toolbox с включённой поддержкой клиентских модов и загрузкой GPK.

Указывать путь к игре не нужно: мод получает его от Toolbox. Отдельные установщики и ручная замена файлов mapper не требуются.

## Установка

1. Полностью закройте TERA и Toolbox, включая значок Toolbox в трее.
2. На странице репозитория нажмите **Code → Download ZIP**.
3. Извлеките из архива папку **`console-hud-master`** и положите её в **`Toolbox/mods/`**. Переименовывать её не нужно.
4. Проверьте расположение файлов:

   ```text
   TERA Toolbox/
   └─ mods/
      └─ console-hud-master/
         ├─ module.json
         ├─ index.js
         ├─ client/
         │  └─ S1UI_CharacterWindow.gpk
         └─ definitions/
   ```

5. Запустите **сначала Toolbox, затем TERA** и войдите на персонажа.

Файл `module.json` должен лежать прямо внутри `mods/console-hud-master/`, без дополнительной вложенной папки. Если основная ветка репозитория называется `main`, папка будет называться `console-hud-main` — она тоже работает без переименования.

Если мод уже установлен под именем `console-hud` или другим именем, сохраните его `config.json` (у старых версий — `module_settings.json`) и уберите старую папку перед установкой. Верните настройки в новую папку. В `mods` должна остаться только одна копия Console HUD.

Вручную копировать GPK в папку игры не нужно. После установки или обновления GPK клиент необходимо запустить заново.

## Управление

| Действие | Как выполнить |
| --- | --- |
| Компактный / развёрнутый вид | Нажать на значок класса |
| Развёрнутый / вертикальный вид в `default` | Нажать на центральную панель |
| Числа / проценты HP | Нажать на шкалу HP |
| Числа / проценты MP | Нажать на шкалу MP |
| Классические венцы Lv65 | `chud classic` |
| Консольные венцы | `chud console` |
| Штатная панель и венцы 100.02 | `chud default` |
| Переключить венцы | `chud toggle` |
| Узнать версию и состояние модуля | `chud status` |
| Перечитать настройки из файла | `chud reload` |

Команды вводятся в **канале Toolbox**. Вместо `chud` можно использовать `consolehud`, например `consolehud classic`. Команды с `/8`, если этот префикс используется вашей сборкой Toolbox, вводятся как `/8 chud classic`.

При первой установке выбраны **классические венцы Lv65**. `classic` и `console` используют нашу панель с разными венцами. `default` возвращает весь штатный Character Window 100.02: HP, MP, классовый ресурс, венцы, ГС и остальные элементы. Все три режима переключаются без перезахода на персонажа и отключения модуля. `toggle` переключает `classic` ↔ `console`; из `default` возвращает `classic`.

Единственное дополнение к штатному виду `default` — клик по центральной панели переключает развёрнутое и вертикальное расположение и сохраняет выбор. Перетаскивание панели не переключает вид.

## Настройки

Toolbox хранит настройки в **`config.json`** внутри папки модуля, например `mods/console-hud-master/config.json`. Выбор венцов сохраняется при вводе команды; редактировать файл для обычного использования не требуется. Для миграции настроек используется `settings_migrator.js`.

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| `enabled` | `true` | Подключать мод при запуске клиента |
| `laurelStyle` | `"classic"` | `"classic"` — наша панель с венцами Lv65, `"console"` — наша панель с созданными нами венцами, `"default"` — штатная панель 100.02 |

После ручного изменения оформления используйте `chud reload`. Изменение `enabled` применяется после перезапуска клиента с Toolbox.

В публикуемую версию личный файл настроек не входит.

При переходе со старой версии мигратор подхватит `module_settings.json`, если `config.json` ещё отсутствует. Существующий `config.json` имеет приоритет.

## Обновление

**Автообновление включено по умолчанию.** При запуске Toolbox штатный обновлятор проверяет `manifest.json` и скачивает изменённые файлы из ветки **`master`** [этого репозитория](https://github.com/Vampical/console-hud). `config.json` не входит в список обновляемых файлов, поэтому ваши настройки сохраняются.

Закройте TERA перед запуском Toolbox с обновлением и дождитесь его завершения, затем запускайте игру. Обновлённый GPK применяется при новом запуске клиента. Проверка обновлений модулей должна быть разрешена в Toolbox; локальный запрет обновлений для Console HUD также должен быть выключен.

В версиях до 0.40 автообновление было отключено — для перехода на 0.40 один раз установите свежий ZIP вручную. В дальнейшем повторно скачивать ZIP не требуется.

Ручное обновление тоже доступно: закройте игру и Toolbox, сохраните `config.json`, скачайте **Code → Download ZIP**, замените папку модуля и верните настройки. Не оставляйте рядом старую и новую копии.

## Удаление

Закройте игру и Toolbox, удалите папку модуля (`mods/console-hud-master`) и запустите клиент заново. Мод загружается через клиентский интерфейс Toolbox; его установка не заменяет файлы mapper на диске.

## Если что-то не работает

**Интерфейс остался прежним.** Проверьте путь `mods/console-hud-master/module.json`, включённую поддержку клиентских модов и порядок запуска Toolbox → TERA. Убедитесь, что другая модификация не заменяет ту же панель персонажа.

**Unknown command.** Войдите на персонажа, проверьте загрузку `console-hud` в журнале Toolbox и попробуйте `chud status` или `consolehud status` в канале Toolbox.

**Ошибка контрольной суммы GPK.** Снова скачайте архив через **Code → Download ZIP** и целиком замените папку модуля при закрытой игре и Toolbox.

**После смены персонажа не применились венцы.** Проверьте `chud status`, затем повторите `chud classic` или `chud console`. Если используете Settings Saver / Settings Fixer, укажите их версии при сообщении о проблеме.

Для обращения в **Issues** приложите версию клиента, версию Toolbox, результат `chud status`, относящиеся к проблеме строки журнала и скриншот.
